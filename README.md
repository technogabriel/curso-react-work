# :rocket: Acerca De:
:construction: Proyecto final del curso de react que emula una tienda online, con navegación dinamica y componentes básicos.  :construction:

# :link: Descargar el proyecto:
`git clone` https://github.com/technogabriel/curso-react-work.git

## Instalar Dependencias:
npm install

## Levantar aplicación:
npm run dev

## :hammer: Funcionalidades del proyecto:
### Componentes:
- `Home`: Pagina principal del proyecto con el logo de la empresa.
- `Login`: login dummy para inicio de sesión.
- `Productos`: Listas de productos disponibles en la web. Se puede filtar por nombre y desde el filtro(search)acceder al detalle.
- `Usuarios`: Muestra el listados de usuarios "registrados" en la pagina. Se puede acceder a cada usuario y ver info. Adicional.
- `Navbar`: Para acceder facil y dinamicamente a las vistas.
- `Footer`: Pie de pagina con información adicional de la web.
- `Header`: Contenedor del Navbar.
- `API Axios`: Para los llamados a las API FAKE(fakeStore App y Rick & Morty App).

## Tecnologias Utilizadas:
- React
- NPM
- Tailwind
- material-tailwind
- Axios
